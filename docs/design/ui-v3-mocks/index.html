Design System — Editorial Instrument
  • Display: Iowan Old Style / Charter / Georgia (serif)
  • Body: system-ui / -apple-system / Segoe UI (sans)
  • Data: Cascadia Mono / SF Mono / Consolas (mono)
  • One accent (#e0a64a amber), used for active state, focus ring, inline code
  • Status triple: dot + bold id + plain sentence (never bare enums)
  • Factory is autonomous end-to-end — only human touchpoint is merge to main
